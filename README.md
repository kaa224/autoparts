# Генератор карточек автозапчастей WDPYD

Утилита находит деталь на `wdpyd.com` по артикулу, загружает фотографию и
применимость, берёт русское наименование из выгрузки 1С и создаёт JPG-карточку
размером 750×1000 px.

## Запуск

```bash
python3 -m pip install -r requirements.txt
python3 generate_card.py 636116 \
  --price /projects/shared/Price_from_1C__to_K.xls \
  --template '/projects/shared/Frame 6.png'
```

Результат сохраняется в `output/636116.jpg`, а все извлечённые данные каталога —
в `output/636116.json`. Для другого каталога назначения:

```bash
python3 generate_card.py 636116 --output-dir /path/to/cards
```

## Правило применимости

- 6 и более производителей: только производители;
- от 3 до 5: производитель и модель;
- менее 3: производитель, модель и детальная спецификация с годами/двигателем.

Если строка не помещается, размер шрифта уменьшается автоматически, а элементы
распределяются между верхней и нижней зелёными плашками.

## Веб-интерфейс

```bash
export AUTOPARTS_TEMPLATE='/path/to/Frame 6.png'
python3 app.py
```

Страница будет доступна на `http://localhost:8000`. Она принимает `.xls` и
`.xlsx` с заголовками `артикул` и `наименование`, показывает ход обработки и
сохраняет пары JPG + JSON в `data/jobs/<номер задачи>/output`. Папку можно
открыть как список файлов в браузере или скачать целиком в ZIP.

Раздел `/archives` показывает все сохранённые пакеты, группирует их по дате
создания и позволяет повторно скачать отдельные файлы или ZIP целиком.

Переменные окружения:

- `AUTOPARTS_TEMPLATE` — путь к PNG-шаблону;
- `AUTOPARTS_DATA_DIR` — каталог хранения результатов;
- `AUTOPARTS_WORKERS` — число одновременно обрабатываемых пакетов;
- `PORT` — порт веб-сервера, по умолчанию `8000`.
- `AUTOPARTS_REQUIRE_AUTH=1` — включает отдельную HTTP Basic Auth;
- `AUTOPARTS_LOGIN` и `AUTOPARTS_PASSWORD` — отдельные учётные данные приложения.

Production-запуск за nginx выполняется одним процессом Gunicorn (состояние
задач хранится в памяти процесса):

```bash
gunicorn --workers 1 --threads 4 --bind 127.0.0.1:8000 app:app
```
